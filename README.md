## ✨ Key Features

### 📖 1. Turn My Trip into a Story (AI Story Generator)
- **Automatic Story Generation**: Synthesizes trip itinerary, routes, diary reflections, meal recommendations, photos, and milestones into multi-chapter narrative books.
- **Strict Factual Guardrails**: Grounded purely on your real travel media and notes—never fabricates unvisited places.
- **Multiple Writing Styles & Voices**:
  - *Styles*: Storytelling, Casual, Humorous, Emotional, Magazine Editorial, Minimal.
  - *Voices*: First Person ("I/We"), Third Person ("The travelers"), Neutral.
- **6 Themed Book Aesthetics**:
  - 📰 **Travel Magazine** — Editorial typography and bold photography.
  - 📔 **Personal Diary** — Intimate scrapbook layout on warm parchment paper.
  - ✨ **Luxury Travel** — Monochromatic, minimal, and sophisticated styling.
  - 🧭 **Adventure Journal** — Coordinates, elevation badges, and field-log styling.
  - 📸 **Polaroid Scrapbook** — Candid photo frames, washi tape accents, and playful stickers.
  - 🎬 **Cinematic** — Widescreen imagery with poetic captions.

### 📚 2. Interactive Digital Book Reader & Story Studio
- **Realistic 2-Page Spread Reader**: Experience stories like an authentic coffee-table book with spine shadows and smooth page-flipping.
- **Story Studio & Page Editor**:
  - Reorder pages up/down, add chapters, or duplicate/delete pages.
  - Live inline text and photo editing with instant updates.
  - **Single-Page AI Controls**: Rewrite, cycle photos, change layouts, make shorter, funnier, or more personal.

### 📲 3. Social Media Sharing & Print Ready Keepsakes
- **8-Slide Instagram Carousel**: Instant export for Instagram Posts (4:5), Stories (9:16), or Square (1:1).
- **Printable Physical Book**: Prepares digital books for physical printing (A4, A5, Square) with 3mm bleed guides and 15mm binding gutters.

## 🚀 Getting Started

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/guruprksh/WanderWall.git
cd WanderWall

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

### Scripts

- `npm run dev`: Starts local Vite dev server
- `npm run build`: Type-checks and creates production bundle
- `npm run preview`: Locally previews production build
